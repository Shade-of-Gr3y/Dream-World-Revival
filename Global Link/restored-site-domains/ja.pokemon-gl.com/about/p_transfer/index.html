ポケモングローバルリンク

『ポケットモンスター X・Y』版PGLへの現行版ユーザー特典について

2013年9月20日　株式会社ポケモン

　いつも「ポケモングローバルリンク（以下、PGL）」をご利用いただき、ありがとうございます。
　2013年7月1日にお知らせしました、『ポケットモンスター ブラック・ホワイト・ブラック２・ホワイト２』版PGL（以下、現行版PGL）のサービス終了に伴い、ご利用いただいている『ポケモンだいすきクラブ』メンバーIDで『ポケットモンスター X・Y』版PGL（以下、X・Y版PGL）にゲームソフトをご登録いただいた際に、現行版PGLのプレイ状況に応じた、X・Y版PGLへの特典について詳細が下記の通り決定しましたので、ご案内申し上げます。

ポケマイルポイントのプレゼント

　現行版PGLで獲得した「ゆめポイント」のポイント数に応じてポケマイルポイントをプレゼントします。
　「ポケマイルポイント」とは、X・Y版PGLの『ポケマイルクラブ』（正式オープン時公開予定）というコンテンツでアトラクションへの挑戦や、ポケマイルストア（ショップ）で道具を手に入れたり、道具を引き替えるために利用できるポイントです。『ポケマイルクラブ』で手に入れた道具はゲームシンクでゲームソフトに送ることができます。
　また、ポケマイルポイントは通常では『ポケモン X・Y』のゲーム内で獲得できるポイントです。ゲームシンクによってPGLに送信して「ポケマイルクラブ」で使うことができます。ゲーム内でのポケマイルポイントの獲得方法については、X・Y版PGLのオープン時にご確認ください。

ポケマイルポイントのプレゼントポイント数
ゆめポイント ※1 　 ポケマイルポイント ※2
10,000ポイント〜49,999ポイント → 500ポイント
50,000ポイント〜99,999ポイント → 3,000ポイント
100,000ポイント〜199,999ポイント → 10,000ポイント
200,000ポイント〜 → 25,000ポイント

※1＝登録いただいたゲームソフトのポイントの合算
※2＝登録いただいた、ソフトそれぞれにポイントをプレゼント

※ゆめポイントは現行版PGLのメンバーIDにご登録いただいている全てのゲームソフトの合算で計算します。
【例】ブラック、ホワイト、ブラック２、ホワイト２の4本を登録いただいている方は4本分のゆめポイントの合算となり、プレゼントするポケマイルポイント数が決定します。

※ポケマイルポイントは、現行版PGLでご利用いただいているメンバーIDへ新たにご登録いただいた『ポケモン X・Y』のそれぞれにプレゼントされます。
【例】プレゼントポイント数が上記の表で10,000ポイントだった場合に、メンバーIDに『ポケモン X』・『ポケモン Y』をそれぞれ一本ずつ、合計二本ご登録いただいた場合は、それぞれに10,000ポイント、合計20,000ポイントをプレゼントします。

特別なメダルの付与

　現行版PGLの各種コンテンツをお楽しみいただいた「遊び込み」の度合いに応じて、記念のメダルをX・Y版PGLに付与します。
メダルはX・Y版PGLにて、『ポケモン X・Y』のゲームソフトやX・Y版PGLのコンテンツのプレイ状況に応じて付与されます。今回のメダルは『ポケモン X・Y』のゲーム内では確認できず、X・Y版PGLのみでご確認いただけます。
この記念メダルは、今回の限定特典として手に入る特別なものです。

対象となる現行版PGLのコンテンツは次の通りです。

ポケモンドリームワールド（PDW）

ゆめポイント獲得ポイント数 → 5万 / 10万 / 20万ポイントでそれぞれ
きのみで購入した家の数 → 1 / 4 / 8 軒でそれぞれ
きのみで購入したインテリアの数 → 1 / 25 / 50個でそれぞれ
きのみで購入したポケモンドールの数 → 1 / 50 / 100個でそれぞれ

グローバルバトルユニオン（GBU）

総合ランキング（各シーズンの最終結果）でベスト100に入ったことがある
※現在開催中のシーズン10は、ランキング最終結果の発表ないため、対象外となります。

Wi-Fi大会

大会に参加してランキングに掲載された回数

  • ※ポイント数や獲得数、ランキング掲載回数等は現行版PGLのメンバーIDにご登録いただいている全てのゲームソフトの実績のそれぞれの数・回数を合算して計算します。
  • ※詳しいメダルの内容については、プレゼント後のX・Y版PGLのメダルのページにてご確認ください。
  • ※メダルの付与は、現行版PGLで利用しているメンバーIDへ新たにご登録いただいた『ポケモン X・Y』のそれぞれにプレゼントされます。

プレゼントのスケジュール

現行版PGLの実績を集計タイミング、プレゼント対象の『ポケモン X・Y』のソフトご登録期限
 2014年1月14日（火）16時
（現行版PGLサービス終了時）
X・Y版PGLへの特典提供タイミング
 2014年1月末予定
※特典提供時には、X・Y版PGLのインフォメーションにて、お知らせさせていただきます。
