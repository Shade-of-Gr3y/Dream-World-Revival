「ポケモングローバルリンク」サービス終了のお知らせ

2013年7月1日　株式会社ポケモン

日頃より弊社商品・サービスをご愛顧いただきまして、誠にありがとうございます。

このたび、『ポケットモンスターブラック・ホワイト・ブラック２・ホワイト２』でご利用いただけるポケモングローバルリンクのサービス（以下：現行PGLサービス）を下記のとおり順次停止させていただき、2014年1月14日（火）をもちまして、終了させていただくこととなりました。

　サービス終了後は、ゲームソフトとの連動や反映等が一切できなくなりますので、下記のスケジュールと内容をご確認くださいますよう、お願い申し上げます。

　また、10月には最新作『ポケットモンスター X』『ポケットモンスター Y』に連動した新しいポケモングローバルリンクのオープンを予定しております。

　これまでポケモングローバルリンクをお楽しみいただいた皆様には、同じメンバーIDにご登録いただいた『ポケットモンスター X・Y』版のポケモングローバルリンクに対して、これまでの記録・実績の一部が反映されるような企画を予定しております。
　『ポケットモンスター X･Y』版のポケモングローバルリンクについて、また、これまでのポケモングローバルリンクをお楽しみいただいた方への企画についてのくわしい情報は、後日公開を予定しておりますので、しばらくお待ちください。

　2010年9月より3年間にわたり、ご利用いただき誠にありがとうございました。ご利用いただきました皆様にはご不便をおかけすることとなり、誠に申し訳ございませんが、何卒ご理解のほど、よろしくお願いいたします。

『ポケットモンスター X・Y』版「ポケモングローバルリンク」についてのご案内は、こちら

現行PGLサービス長期メンテナンスについてのご案内

2013年10月1日（火）16:00〜12日（土） 予定

現行PGLにつきまして、長期メンテナンスを実施いたします。

  • メンテナンス期間中、『ポケットモンスターブラック・ホワイト・ブラック２・ホワイト２』にて「ゲームシンク」ができません。ねむらせていたポケモンを『ポケットモンスターブラック・ホワイト・ブラック２・ホワイト２』で起こすことができませんので、事前にポケモンドリームワールドにて「ポケモンを起こして終了」を選択していただき、ポケモンを起こすことをおすすめします。
  • メンテナンス期間中、『ポケットモンスターブラック・ホワイト・ブラック２・ホワイト２』の「Wi-Fiランダムマッチ」レーティングモードがご利用いただけません。
  • メンテナンス期間中、『ポケットモンスターブラック２・ホワイト２』の、Wi-Fi通信を使っての「おもいでリンク」がご利用いただけません。

現行PGLサービスを、順次停止いたします。

2013年10月12日（土） 予定〜

ゲームソフトの登録・追加登録ができなくなります。さらに、新規PGL利用登録もできなくなります。

▲「ゲームソフトの追加登録」ができなくなります。
▲「新規PGLユーザー登録」ができなくなります。

「体験版」ポケモンドリームワールドのサービスを停止いたします。

以下のサービスは、引き続きお楽しみいただけます。

  • ・「ポケモンドリームワールド（PDW）」　※体験版ではご利用いただけません。
  • ・「グローバルバトルユニオン（GBU）」
    ※現在開催中の「シーズン10」は、引き続き対戦をお楽しみいただけますが、最終結果集計〜発表については予定しておりません。
    ご了承ください。
  • ・「グローバルトレードステーション（GTS)」
  • ・「Wi-Fiランダムマッチ」レーティングモード、フリーモード

2013年12月10日（火） 予定〜

「ゲームシンク」はできますが、ポケモンを新たにねむらせることができなくなります。
※『ポケットモンスターブラック２・ホワイト２』にて、関連するメダル「おやすみなさい」の入手ができなくなります。したがって、メダルを集めるきることができなくなるため、「キングオブメダリスト」「アドベンチャーキング」も入手不可となります。あらかじめご注意ください。

ねむらせているポケモンを起こすことはできます。

ポケモンを起こすことで、PDWでなかよくなったポケモンをゲームソフト側に連れて行ったり、PDWで入手したどうぐを持ち帰って受け取ったりすることはできます。
また、起こしたときに、PGLにて選択している「Cギア」、「ミュージカル」、「図鑑スキン」が、ゲームソフト側に反映されます。それ以降は、変更ができませんので、あらかじめご注意ください。

DS
▲ねむらせるポケモンを選択する画面を見ることはできますが、すべてのポケモンにおいて、選択することができなくなります。
PDW
▲『ポケモンを起こす準備をして終了』を押して、ゲームシンクを行ってください。
【ご注意】このゲームシンクが、ゲーム側への最後の持ち帰りとなります。以降、PDWへ進むことができなくなりますので、お確かめのうえ画面操作を行ってください。
PGL
▲選択したCギア、ミュージカル、図鑑スキンが、反映されます。
【ご注意】ポケモンを起こす前の段階で選択しているCギア、ミュージカル、図鑑スキンが、ゲームソフト側に反映されます。
起こした後は、PGLの画面内で選択する操作はできますが、ゲームソフト側に反映させることはできません。

現行PGLサービスを、すべて終了いたします。

2014年1月14日（火） 16:00 (予定)〜

現行PGLサイトへアクセスすると、「終了告知画面」が表示されます。

『ポケットモンスターブラック・ホワイト・ブラック２・ホワイト２』のゲームソフトにて、ねむらせているポケモンを起こすことのみができます。
※起こすときに、PDWでなかよくなったポケモンをゲームソフト側に連れて行ったり、PDWで入手したどうぐを持ち帰って受け取ったりすることはできません。Cギア、図鑑スキン、ミュージカルの変更もできません。あらかじめ、2014年1月13日（月・祝）までに受け取ってください。

グローバルトレードステーション（GTS）で、ポケモンを交換することはできますが、現行PGLで交換の履歴を見ることができなくなります。

「Wi-Fiランダムマッチ」レーティングモードで、対戦することはできなくなります。

「Wi-Fiランダムマッチ」フリーモードは、引き続きお楽しみいただけます。

ハイリンクの森へポケモンを連れていくことができなくなります。したがって、『ポケットモンスターブラック２・ホワイト２』において、関連するメダル「うとうとキャプチャ―」「すやすやキャプチャ―」「ぐっすりキャプチャ―」「ゆめであいましょう」の入手ができなくなります。あらかじめご注意ください。
