Because Yamaha is a company, the .midi files they made dont work as well when used by other .midi players. These are the steps to playing the file optimally



1\. Download and install YAMAHA MidRadio Player(English translation) from this link below 

[https://www.facebook.com/groups/xgcentral/posts/9413018445441443/](https://www.facebook.com/groups/xgcentral/posts/9413018445441443/)



2\. Open the application, and select "File"
3. Select the .midi file you want to open
4. Press Play
